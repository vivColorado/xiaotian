# 主会话设计

## v32 · 2026-10-16

主会话先让用户容易表达，再让进展容易读。每次交流是一组：您的吩咐在右侧，小天的回应在左侧，相关任务卡紧接回应；不用重复头像、动作标题和多行时间说明。

第一句只保留“有什么事，直接吩咐我就好。”。更早的自动记录收起，需要时展开。购物用例完整展示创建、需要协助、用户补充和完成；这些回执不会随任务现状改写，点击都进入任务最新详情。

卡片只有三个层次：标题与小号状态、两行进展摘要、必要元信息与详情入口。完成浅绿、需协助浅蓝；其他常规状态默认底色，暂停／取消／异常同一灰色。用户消息使用暖米色，避免与状态混淆。批量默认展开、双列紧凑、约半屏限高；更多任务在组内滚动，每条更新独立记忆折叠与滚动。

阅读旧消息时收到更新，不抢滚动位置，以“几条新进展”提示。点击回到最新；正在底部时自然跟随。切去工作台再回来保留阅读位置，现有左／右滑和右侧椭圆切页入口保持。

输入默认收起。短按语音开始，再按结束；不弹框，可同时浏览。轻量“打字”入口打开同一输入区。未发内容可收起后继续编辑，固定约 40px、手动展开约 136px。Enter 换行，点击发送或 Ctrl／⌘ + Enter 发送，中文组词不误发。

补充任务时明确显示任务名，可取消关联。显式选择优先于关键词；语音和暂存都保留关联，发送或暂存结束清除旧上下文。停止录入不会执行，暂存不会创建任务。空输入禁用发送和暂存。

## 验证范围

`node tests/conversation.cjs` 检查数据和交互状态；几何尺寸使用模拟 DOM，不能证明实际手机视觉与触摸体验。浏览器和 iOS／Android 真机尚待验收。真实语音、外部账号和任务执行未接入。

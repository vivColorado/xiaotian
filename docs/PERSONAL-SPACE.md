# 个人空间与亲子出游

## v34 · 2026-10-17

个人空间是小天的第三个主页面。它把“帮我把事情办好”延伸为“帮我记住自己如何生活”：概要看一天，自己看健康和好奇，生活看周末与足迹，小包看成长与照护。累计数字从实际展示的记录计算，示例记录明确标注，不能当作真实服务成果或健康数据。

## 信息与视觉

- 暖纸色底、低饱和绿、轻量衬线标题与秋日原创矢量插画，区别于会话和工作台。
- 概要：累计留痕、足迹与成长瞬间；七日日历、月份选择与直接选日期；每日小结；生活封面；个人小应用；近期成长。
- 自己：血糖、体重趋势；模拟血糖仪同步；论文阅读笔记和科技主题追踪。数值与阅读是可编辑的示例，不自动做医疗判断。
- 生活：年度周记录、地点索引、周末经历。保留“加班有点惨”等普通时刻，不只保存精彩成就。地点入口筛选其对应记录。
- 小包：出生日期、按演示日期计算月龄、身高体重、所有第一次、新生儿喂养和照护观察。
- 成长故事按用户提供的日期导入；“2.24.12.10”按上下文整理为 2024-12-10。周末第六周以后的内容保留补记入口，不编造经历。

## 可用的小应用

默认提供血糖手账、轻盈计划、阅读与追踪、小包成长、喂养日志、照护观察。记录有日期、可选时间、标题、备注；数值应用另有测量值与趋势图。身高体重同时保留两项值。喂养保留历史阶段，不把新生儿数据当作现在的需求。

“按需构建”选择文字或数值模板，填写名称、所属领域及可选单位，生成可用表单、历史记录列表与时间线；数值型生成趋势。可以添加、编辑、确认删除记录，收起并恢复应用，导出整个个人空间 JSON。收起应用不删除数据。当前是前端模板构建，不宣称已接入模型生成任意应用。

日期和数值要校验；不接受无效日期、超过演示今天的回溯记录、空标题或无效数值。所有用户文本进行 HTML 转义。localStorage 保留当前浏览器状态，不向服务器上传健康与家庭记录。设备同步按钮只生成一条明确标注的示例，不重复插入。

只有一个出游任务，各阶段卡片保留当时快照，点击打开最新详情。最新详情包含当前需决定的信息，并提供回会话继续的入口。暂停、取消后不能通过场景按钮继续推进。真实注册、预约、导航、支付、检索和照片上传尚未接入；真实上线需依据地址、活动链接、权限和实际工具结果执行。

晚间生成两条共享 sourceTask 的记录：

- 生活记录：带小包挖红薯去咯，含农场地点；足迹从生活记录的地点派生，不另造重复记录。
- 成长记录：第一次挖红薯。

会话、生活、足迹、成长可相互追溯。重复点击、重复完整回放和刷新不重复生成。单独删除一条记录不删除其余关联记录。

## 三页面导航

顺序为吩咐我 → 工作台 → 个人空间。向左前进、向右返回，首尾不循环，顶部同样支持。三个小点与页码提示位置，不恢复顶部双按钮或底部导航。

右侧贴边椭圆入口短按展开三个目的地，点选后切页；点击外部或 Esc 收起。保留长按拖动与右侧吸附。会话阅读位置、工作台与个人空间纵向位置、未发送输入及正在进行的语音模拟保留。工作台日历缩放、内部滚动和个人日期区不被页面手势劫持。

回顾卡可直接进入对应个人记录；“回看这一天的会话”返回回放开始处。页面切换不等同于离开 App，原在线／离开消息逻辑继续有效。

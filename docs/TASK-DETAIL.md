# 任务详情设计

## v31 · 2026-10-16

详情打开后首先回答：进展如何，现在需要我做什么。

1. 任务标题与轻量状态。标题支持换行，关闭入口固定可达。
2. 最新进展。默认打开，可手动折叠。普通状态白底，需协助浅蓝，完成浅绿，中断状态统一中性色。
3. 需求与过程。浅色折叠行，默认收起。保留原始材料、补充、步骤和已答确认记录。
4. 任务管理。暂停、取消、重开、主题和附件管理默认收起，终态不显示无效操作。
5. 补充信息。底部可达，进入关联当前任务的输入框，继续语音时保持上下文。

需协助的问题和选项放在一起，不再单列确认模块。完成结果保留所有产出附件入口，不同时重复渲染附件和大图。未完成的支付等交接在结果下方说明，不改写任务完成状态。

后台更新保留详情滚动位置与各折叠区状态。关闭后重新打开，恢复默认展开规则。手机端允许整体滚动，正文不截断，选项允许换行。

本版是前端交互原型，外部执行与语音转写仍为模拟。没有改变授权边界或服务接入情况。

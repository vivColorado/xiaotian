# 小天

人生归你，琐碎归我，愿你自在每一天。

面向日常生活的 AI 个人助理交互原型。当前版本为 v33。初始导入基于演示站点提交 `7ed9d183d660f72347a34d60e31c886bb64f1085`。

## 本地运行

无需安装依赖或构建。安装 Python 3 后，在项目根目录运行：

```bash
python3 -m http.server 8080 --directory dist
```

浏览器访问 http://localhost:8080 。

## 目录

- `dist/`：HTML、CSS、JavaScript 与演示附件，可直接部署到静态服务器。
- `docs/REQUIREMENTS.md`：需求文档 v0.9，作为当前需求依据。
- `docs/TASK-DETAIL.md`：任务详情布局与交互设计。
- `docs/CONVERSATION.md`：主会话阅读、输入与滚动规则。
- `docs/DELIVERY.md`：在线消息、离开汇总、提醒与出席的状态边界。
- `tests/conversation.cjs`：主会话关键交互的模拟 DOM 回归检查。
- `CHANGELOG.md`：版本改动记录。
- `docs/xiaotian-brief.html`：可离线打开的产品汇报。
- `dist/assets/`：演示附件与历史下载包。该目录内需求及设计文档属于历史版本。

## 体验范围

自然吩咐、任务回执、必要确认、结果交付、当天工作台、周期任务、主动关心、批量任务卡与详情追溯。

当前为前端 Demo：语音与任务执行使用模拟数据，状态保存在浏览器 localStorage。真实电商执行、支付、语音识别、后台调度和跨设备同步尚未接入。清除站点数据会重置本地演示状态。

## 版本管理

建议以 main 保存可运行版本，需求修改通过独立分支和 Pull Request 合入。GitHub 仓库管理与现有演示站点发布独立，推送代码不会自动发布站点。


## 交互检查

安装 Node.js 后运行 `node tests/conversation.cjs`，核查历史快照、任务关联、批量卡状态、阅读位置和暂存。运行 `node tests/delivery.cjs` 核查在线／离开消息、重入汇总、提醒去重及详情手势。该检查不替代浏览器视觉及 iOS／Android 触摸验收。


## v33 演示入口

主会话第一句下方点“体验消息流程”。日期固定为 2026-10-15，初始 18:45；依次体验在线更新、离开后返回、全部任务汇总、创建游泳提醒、到 19:30。时间由演示按钮推进，不依赖设备真实日期。

在输入框发送“全部任务怎么样？”会生成汇总。发送“今天晚 8 点我要去游泳，提前半小时通知我”会设置指定演示提醒。其他时间的自然语言提醒尚未接入通用解析器，不会悄悄按固定时间执行。

网页可见／隐藏、重新打开使用同一待呈现队列；关闭网页期间没有真实后台调度或系统 Push 服务，演示按钮用于模拟这段时间的事件。待办提醒与任务卡分开，收到或知晓提醒不等于已完成线下事项。
